### Target concrete building, distinct layers
1. **Ingress / verify:** only Dhan read-only via Oracle secured shared gateway; stamp receiving time separately from Dhan source time. Validate symbol, source, timeframe, expiry, finite price/valid OHLC and generation.
2. **Bounded stock:** immutable last-good snapshot by (generation,symbol,stream,timeframe,expiry); bounded history ring-buffer, freshness state HIST/STALE/WAIT; avoid stacking identical quote revisions. 4. **Apply queue:** independent per-screen priorities: visible Watchlist/Dashboard/Scanner first, offscreen deferred; bounded latest-value coalescing, generations guard, per-frame time budget based on phone measured jank/CPU/memory, starvation prevention and exponential error backoff. 5. **Mounted delta renderer:** fixed row/card/control identity, update only changed fields, active candle tail and affected chart bars; do not remount whole page/scroll/chart for each tick.
